# Algorithm Study

[백준 온라인 저지(BOJ)](https://www.acmicpc.net)와 [solved.ac](https://solved.ac) 문제 풀이 및 알고리즘 이론 학습을 정리한 저장소입니다.

주로 **Python**으로 풀이하며, 일부 문제는 **C++**로도 작성되어 있습니다.

## 📂 디렉터리 구조

```
algorithm/
├── solved_ac/          # solved.ac CLASS 단계별 문제 풀이
│   ├── CLASS 1/        # 입출력, 사칙연산 등 기초 (4)
│   ├── CLASS 2/        # 배열, 정렬, 수학, 자료구조 입문 (20)
│   ├── CLASS 3/        # 그래프(BFS/DFS), 힙, DP 기초 (40)
│   ├── CLASS 3 복습/    # CLASS 3 ESSENTIAL 문제 복습
│   ├── CLASS 4/        # 최단경로, 트리, DP, 백트래킹 (47)
│   │   ├── ESSENSIAL/  # 필수 문제
│   │   └── ++/         # 추가 문제
│   └── Not A CLASS/    # CLASS 외 문제
│
└── 이론/                # 알고리즘 이론 및 구현 정리
    ├── greedy/         # 그리디
    ├── 길찾기/          # BFS, DFS(스택/재귀), 격자 탐색
    ├── 다이나믹 프로그래밍/ # DP
    ├── 이진탐색/         # 반복문 / 재귀 구현
    ├── 자료구조/         # 최대 힙, 최소 힙
    └── 최단 경로/        # 다익스트라, 벨만-포드, 플로이드 워셜, 0-1 BFS
```

## 📝 파일 규칙

- 파일명은 대체로 `문제번호 문제이름.확장자` 형식을 따릅니다.
  - 예: `1697 숨바꼭질.py`, `2805_나무자르기.cpp`
- 같은 문제에 대해 여러 접근(`정답`, `재풀이`, `최적화`, `시간초과` 등)을 함께 보관하기도 합니다.
  - 예: `7576 토마토 정답.py`, `7576 토마토 실패.py`

## 🛠️ 실행 방법

```bash
# Python
python "algorithm/solved_ac/CLASS 3/1697 숨바꼭질.py"

# C++
g++ -o solution "algorithm/solved_ac/CLASS 2/2805_나무자르기.cpp"
./solution
```

대부분의 문제는 표준 입력(`stdin`)으로 값을 받습니다. 입력은 백준 문제 페이지의 예제를 참고하세요.
